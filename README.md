# 《列国》· 世界历史人物志

一期一人，按**文明／国家**归档的世界历史人物志期刊。全部为**单文件 HTML**（插画、舆图全部 base64 内嵌），
可离线打开、可打印成 PDF，**不依赖任何 CDN 或外链资源**。

线上站点：**http://139.196.5.123/abroad-history-magazine/**
本仓库即线上站点的**唯一源**：仓库根目录 = 站点根目录。

> 与同一服务器上的《列传》（中国历史人物志，`/history-magazine/`）互为姊妹刊：
> 同一套出版体例（正史与一手文献 + 图表 + 想象插画 + 依真实经纬度绘制的舆图 + 两造对读），
> 但**分类维度改为文明／国家**，**版式为西方骨架**（双线书框 + 齿饰带 + 柱式章头 + 页边批 +
> 拉丁小题 + 月桂徽记），两刊的容器名、色值、字体栈互不复用。

## 发布方式（CI/CD）

**不要手动 scp 上传。** 把改动 push 到 `main` 即可，GitHub Actions 会自动完成整条链路：

```
push 到 main
   ↓
配置 SSH（私钥来自仓库 Secrets）
   ↓
上传前先在服务器端 tar 备份到 /root/ahm-backup/
   ↓
tar 管道上传到 /usr/share/nginx/html/abroad-history-magazine/
   ↓
服务器端 sha1sum 逐文件比对（本地 ≠ 线上则整个 job 失败）
   ↓
公网 curl 实测 HTTP 状态码
```

### 必须配置的 Secrets

| 名字 | 说明 |
|---|---|
| `DEPLOY_SSH_KEY` | 部署用 SSH 私钥（OpenSSH 格式，ed25519） |
| `DEPLOY_HOST` | 服务器 IP / 域名 |
| `DEPLOY_USER` | 登录用户 |
| `DEPLOY_PATH` | 站点根目录绝对路径 |

写入方式：`python ../_gh_secrets.py --set`（走 REST API + libsodium 密封盒，无需 gh CLI）。

### 手动触发

`Actions` → `Deploy 到 ali-claw` → `Run workflow`（`workflow_dispatch`）。

## 新增一期的流程

1. 在 `../` 下新建单期工程目录 `<slug>`，产出 `index.html` 单文件 + 封面缩略图 `_thumb1.jpg`；
   （若沿用第 01 期的骨架，可直接复制 `caesar-rubicon-1/` 整套工具链，再换 `parts/00_head.html` 的色值与构件）
2. 在 `../_deploy_prep.py` 的 `CATALOG` 末尾追加一条记录，**`civilization` 必须填**为
   `CIVILIZATIONS` 里已定义的 key（否则脚本直接报错退出）；
3. 跑 `python ../_deploy_prep.py` —— 刊库首页会自动按文明分组、排序（按文明起始年，公元前为负数）、
   分页，并把单期复制进 `./<slug>/index.html`，最后打印全部文件的 SHA1；
4. `git add -A && git commit -m "第 02 期《XX》· XXX" && git push`；
5. 等 Actions 变绿 —— sha1 比对不过就是红的。

## 校验哲学

- **不信上传工具的退出码**（`scp` 曾静默失败、`tar` 管道也可能只传一半），只信**服务器端算出来的 sha1**；
- **备份永远在上传之前**，且备份文件留在服务器 `/root/ahm-backup/`；
- 部署失败**不写摘要**，宁可红着让人看见，也不要"看起来成功"。
